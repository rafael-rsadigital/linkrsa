# Fotos da empresa

Coloque aqui as fotos reais da empresa, produtos ou serviços.

Sugestões de nomes:

- `hero.jpg` para a imagem principal;
- `sobre.jpg` para a seção institucional;
- `video-cover.jpg` para a capa do vídeo;
- `produto-01.jpg`, `produto-02.jpg` etc. para a vitrine.

Depois atualize os campos `media` e `categories` em `site-config.js` para apontar para `/assets/nome-do-arquivo.jpg`.
